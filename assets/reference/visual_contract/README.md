# Referências Visuais Integradas

O ponto de entrada é `docs/16_VISUAL_REFERENCE_INDEX.md`. Referências aprovadas são
organizadas por finalidade: `anchors/`, `maps/`, `sectors/`, `construction/`,
`vehicles/` e `baselines/`. O manifesto contém hash e status de cada artefato.

`maps/world_map_reference_02.png` é a referência macro ativa. `baselines/` contém
as capturas aprovadas para regressão. As demais pastas guiam a construção de setores,
estruturas e veículos. As imagens são contratos de produção, não texturas runtime.
